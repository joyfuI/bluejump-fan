# 블루점프 팬 사이트

[블루점프](https://bluejump.co.kr/) 팬 사이트입니다.

## 기능

* 라이브 모아보기: 현재 방송 중인 멤버를 확인할 수 있습니다.
* 캘린더 모아보기: 숲 방송국 캘린더의 내용을 가져오는 거라 스트리머가 캘린더 기능을 사용하지 않는다면 뜨지 않습니다. 우측 위 드롭다운 메뉴로 과거 캘린더도 확인할 수 있습니다.
* 방송국글 모아보기: 방송국 게시판 글 목록을 불러옵니다. 방송국별로 첫 번째 페이지만 불러옵니다. 우측 하단의 필터 기능으로 원하는 스트리머 글만 표시할 수 있습니다.
* 카페글 모아보기: 팬카페의 스트리머 전용 게시판 글 목록을 불러옵니다. 카페 게시판별로 첫 번째 페이지만 불러옵니다. 우측 하단의 필터 기능으로 원하는 스트리머 글만 표시할 수 있습니다.
* 다시보기 모아보기: 다시보기를 한 번에 모아서 보여줍니다. 방송국별로 첫 번째 페이지만 불러옵니다. 우측 하단의 필터 기능으로 원하는 스트리머 다시보기만 표시할 수 있습니다.
* 노래책: 노래책이 존재하는 멤버의 노래책을 한 번에 볼 수 있습니다. 멤버 간의 겹치는 노래를 확인할 수 있으며, 해당 리스트는 수동으로 업데이트하고 있으니 최신 정보는 원본 노래책을 확인해주세요.
* 키리누키 목록: 블루점프 키리누키를 정리했습니다. 추가/삭제 요청은 사이트 내 메일 주소로 연락주세요.
* 팬카페: 블루점프 멤버들의 팬카페 링크입니다.

방송 도구
* 댓글 실시간 업 랭킹: 숲 댓글 실시간 업 랭킹을 보여줍니다. 게시글 주소를 입력하면 되며, 하이라이트 ID를 지정하면 해당 ID를 스크롤로 따라가며 보여줍니다.
* 댓글 링크 생성기: 게시글 주소와 찾을 댓글의 ID/닉네임을 입력하면 해당 댓글로 바로 이동하는 링크를 생성해 줍니다.
* 다시보기 썸네일 생성기: 블루점프 멤버들의 숲 다시보기 썸네일 생성기입니다.

### 라이브 시작 알림 설정

멤버가 방송을 시작하면 데스크톱 알림을 표시합니다. 아래 안내에 따라 브라우저 알림 권한을 허용해야 합니다.

**블루점프 팬 사이트가 브라우저 탭에 열려 있는 동안에만 작동**하며, 사이트나 브라우저를 완전히 닫으면 알림을 받을 수 없습니다. 백그라운드 탭에서는 브라우저 정책에 따라 알림이 늦어질 수 있습니다. 모바일 브라우저와 시크릿 모드에서는 정상 동작을 보장하지 않습니다. 알림 권한을 변경한 뒤에는 사이트를 새로고침해 주세요. 운영체제의 알림 설정에서도 사용 중인 브라우저의 알림이 허용되어 있어야 합니다.

#### Chrome

1. 블루점프 팬 사이트를 엽니다.
2. 주소창 왼쪽의 사이트 정보 아이콘을 누르고 `사이트 설정`을 엽니다.
3. `알림`을 허용으로 변경합니다.
4. 사이트를 새로고침합니다.

[Chrome 알림 설정 안내](https://support.google.com/chrome/answer/3220216)

#### Firefox

1. 블루점프 팬 사이트를 엽니다.
2. 주소창 왼쪽의 자물쇠 아이콘에서 사이트 정보와 권한 설정을 엽니다.
3. `알림 보내기` 권한을 허용으로 변경합니다.
4. 사이트를 새로고침합니다.

[Firefox 알림 설정 안내](https://support.mozilla.org/kb/push-notifications-firefox)

#### Edge

1. 블루점프 팬 사이트를 엽니다.
2. 주소창 왼쪽의 사이트 정보 아이콘을 누릅니다.
3. `이 사이트에 대한 권한 > 알림`을 허용으로 변경합니다.
4. 사이트를 새로고침합니다.

[Edge 알림 설정 안내](https://support.microsoft.com/edge/manage-website-notifications-in-microsoft-edge)

#### Safari

1. Safari에서 `Safari > 설정 > 웹사이트 > 알림`을 엽니다.
2. 블루점프 팬 사이트를 찾아 허용으로 변경합니다.
3. macOS의 `시스템 설정 > 알림`에서도 Safari 또는 해당 웹사이트의 알림을 허용합니다.
4. 사이트를 새로고침합니다.

[Safari 알림 설정 안내](https://support.apple.com/guide/safari/ibrwe2159f50/mac)

## 개발 환경 설정

```bash
# 의존성 설치
pnpm install

# 개발 서버 실행
pnpm run dev
```

개발 서버가 실행되면 [http://localhost:3000](http://localhost:3000)에서 확인할 수 있습니다.

## 빌드 및 배포

```bash
# 프로덕션 빌드
pnpm run build

# 빌드 서버 실행
pnpm run preview
```
